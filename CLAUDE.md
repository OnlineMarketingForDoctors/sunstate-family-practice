# Sunstate Family Practice website

## The site must not be indexed by search engines

This site must stay out of search results until the owner explicitly says otherwise. Every change must keep all three layers below in place:

1. **HTTP header:** `vercel.json` sends `X-Robots-Tag: noindex, nofollow` on every path. Don't remove or narrow it.
2. **Meta tag:** every HTML page, template and layout includes
   `<meta name="robots" content="noindex, nofollow">` in its `<head>`. If you use a framework, put it in the root layout so no page can miss it.
3. **No sitemap:** don't generate a `sitemap.xml` or submit the site to search consoles.

Don't add `Disallow: /` to `robots.txt`. A crawler that is blocked from fetching a page never sees its noindex header or tag, so the URL can still show up in results. If you add a `robots.txt`, leave crawling allowed.

## How the site is built

The pages are static HTML generated by `tools/build/build.py` (Python 3 + Jinja2):

```
python3 tools/build/build.py
```

- `tools/build/templates/base.html` holds the shared `<head>` (including the noindex meta tag), header, footer and scripts. Every page extends it.
- `tools/build/templates/home.html` and `fees.html` are the hand-built homepage and fees page. Edit them there, not the generated `index.html` files.
- All other pages are rendered from `tools/build/content/live.json`, the content extracted from the live WordPress site, using the layouts in `tools/build/render.py` and the page builders in `build.py`.
- `tools/build/sitedata.py` holds the navigation, doctors, services, suburbs and news topics.
- Pages are written to the same URL paths as the live site (for example `about-us/index.html`). Old URLs the live site redirects are mirrored in `vercel.json` and in `REDIRECTS` in `render.py`.

Rebuild after any template or content change and commit the generated HTML. `.vercelignore` keeps `tools/` and client documents out of the deployment.
